# RimWorld mods

A RimWorld 1.7 modding workspace built primarily for AI coding agents.
Codex and Claude Code both work well with it. The shared tools can also be used
directly.

## Published mods

**KanbanStockpile-Refilled** — stack limits and refill thresholds for stockpiles
and shelves. Requires RimWorld 1.7 and Harmony.

[Source](https://github.com/eiennohito/rimworld-kanbanstockpile-refilled) ·
[Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3832323892)
